# CODSOFT_TASKSNO2

Task Management & Workflow

You can manage your tasks efficiently through a clean interface. Here's how the main features work:

· Task Creation & Editing: Use the "Add Task" button to open a modal form. Fill in the title, description, category, priority, and due date. You can edit any existing task by clicking the pencil icon on a task card.
· Filtering and Search: The toolbar provides powerful filtering options. You can search by keywords, filter by status (All/Pending/Completed), priority (High/Medium/Low), and category. The task list updates instantly.
· Task Status & Tracking: Each task has a checkbox to mark it as complete. The dashboard's statistics (Total, Completed, Pending, Overdue) update automatically, giving you a quick overview of your progress.
· Data Persistence: All your tasks and the dark/light theme preference are saved in your browser's local storage. Your data will persist even after you close or refresh the page.
